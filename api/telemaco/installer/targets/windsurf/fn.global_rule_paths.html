Global rule files, one per agent that reads one.

Cascade keeps its global rules in ~/.codeium/windsurf/memories/. The Devin CLI does not read that file: its user-level rules are ~/.devin/rules/*.md and ~/.devin/global_rules.md, with the same trigger frontmatter a project rule uses (docs.devin.ai/cli/extensibility/rules). A global install that wrote only the Cascade file left the default agent with nothing.
