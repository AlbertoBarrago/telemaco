§dom: Option<DomTree>§url: String§encoding: String

WHATWG canonical name of the document’s character encoding (e.g. “UTF-8”, “EUC-JP”). Backs document.characterSet and the URL query encoding override for <a>/<area> hrefs in legacy-charset documents.

§title: String§referrer: String

URL of the document that initiated this document’s navigation. Direct browser/API navigations leave this empty; document-initiated navigations set it to the source document URL.

§blocked_urls: Vec<String>§cookie_jar: Option<Arc<CookieJar>>§http_client: Option<Arc<TelemacoHttpClient>>§callbacks: Option<Arc<CallbackRegistry>>

The owning page’s passive on_request/on_response callbacks (issue #408). Page-scoped, so scripted fetch()/XHR observation stays local to the page that registered it.

§pending_navigation: Option<(String, String, String)>§intercept_tx: Option<UnboundedSender<InterceptedRequest>>§intercept_counter: u64§intercept_enabled: bool§pending_binding_calls: Vec<(String, String)>§pending_runtime_events: VecDeque<RuntimeEvent>§runtime_events_enabled: bool§runtime_exception_counter: u64§network_response_bodies: HashMap<String, StoredNetworkResponseBody>§network_response_body_order: VecDeque<String>§network_response_body_counter: u64§fetched_urls: Vec<String>§js_network_events: Vec<JsNetworkEvent>§pending_frames: Vec<PendingFrame>§pending_frame_bytes: usize

Total URL and HTML bytes held by pending_frames.

§frame_id_counter: u32§frame_id: u32

Which frame this state belongs to; 0 is the page’s own realm.

§pending_frame_messages: Vec<PendingFrameMessage>§pending_frame_message_bytes: usize

Bytes of payload currently queued above, tracked rather than summed so the cap costs nothing per message.

§page_in_flight: Arc<AtomicU32>

Requests initiated by this runtime only. Browser contexts share their transport client across pages, so the client’s aggregate counter cannot be used as a page-readiness signal.

§activity_generation: u64

Monotonic generation for observable changes to the connected document. The browser settle policy samples this to distinguish useful deferred rendering work from unrelated long-lived timers.

§document_generation: u64

Monotonic identity of the currently installed document. Async resource completions use this to discard bytes and lifecycle results belonging to a navigation that has already been replaced.

§base_url_cache: RefCell<Option<BaseUrlCache>>

Cached document base URL. Computing it walks the tree and runs the selector engine, and the JS layer asks for it on every relative URL, including the URL parts of <a>. Interior mutability so the read path keeps its shared borrow.
