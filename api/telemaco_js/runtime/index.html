WatchdogToken
Handle to an armed V8 execution watchdog (see TelemacoJsRuntime::arm_watchdog). Holds the cancel channel and the watchdog thread; pass it back to disarm_watchdog to stop the watchdog and learn whether it fired.

is_fatal_event_loop_error
Whether an event-loop task error is fatal to the page or page-local noise. deno_core reports a task’s uncaught exception and an unhandled promise rejection as an event-loop error, but a browser treats both as page-local: window.onerror / unhandledrejection fire and later tasks still run. Only engine-level failures (watchdog termination, the heap cap, an exhausted task budget) make the loop itself unusable. (#699)
spawn_watchdog
Arm a V8 termination watchdog directly from an isolate handle, with no runtime borrow. The CDP dispatcher uses this to bound every command so a hung page cannot hold this connection’s V8 lock forever. Pair with WatchdogToken::stop; if stop returns true, clear the termination flag via TelemacoJsRuntime::cancel_termination before reusing the isolate.
