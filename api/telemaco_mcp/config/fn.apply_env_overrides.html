Apply environment overrides on top of base.

The lookup is injected rather than read from the process environment so the precedence rules can be unit-tested without mutating global state, following navigation_timeout_from_env_value in telemaco-browser.

An unparsable value is ignored and leaves the lower layer in place: a typo in a shell export must not silently clamp output to zero.
