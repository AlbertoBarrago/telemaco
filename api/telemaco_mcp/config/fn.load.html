pub fn load(explicit: Option<&Path>) -> Result<ExtractionLimits>
Expand description

Resolve the limits for this process: defaults, then the config file, then the environment. CLI flags are layered on by the caller, and tool arguments per call, so this is everything below those two.

A malformed or unreadable config is a hard error at startup rather than a fallback to defaults: a broken config that silently does nothing is worse than a server that refuses to start.
