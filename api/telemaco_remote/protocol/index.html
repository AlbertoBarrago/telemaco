Expand description

Telemaco remote protocol, version 1.

Wire format: each message is a frame of a 4-byte big-endian length followed by that many bytes of UTF-8 JSON. JSON through serde into closed enums with deny_unknown_fields means untrusted input can only ever become one of the listed message shapes; there is no type-directed deserialization. Frames are capped at MAX_FRAME_BYTES.

Session: the client sends Request::Hello first; the agent answers Response::Hello or an unsupported_version error and closes. After that, each request gets exactly one response, in order.
