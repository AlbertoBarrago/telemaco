Module tailcat_server 

Source
Expand description

Server side of the Tailcat transport: remote serve.

Runs tailcat serve --key=new --json exec -- <agent argv>. Tailcat’s exec service starts the agent once per incoming connection with the connection as its stdio, so the only thing reachable through the tunnel is the Telemaco protocol: no local port is exposed, nothing on the LAN, and no exit node. The address comes from the {"listenAddr": ...} line that --json writes to stdout, not from scraping the decorated stderr.

Tailcat’s stderr (its own notices plus every agent’s diagnostics) is relayed line by line with any address-shaped token redacted, because tailcat itself prints the full address there.
