Expand description

A way to open a byte stream to a remote agent.

Required Methods§

Source

fn kind(&self) -> TransportKind

Which transport this is, for status output and diagnostics.

Source

fn connect( &self, ) -> impl Future<Output = Result<Connection, TransportError>> + Send

Opens a new stream to the agent. Each call is an independent session.

Provided Methods§

Source

fn path( &self, ) -> impl Future<Output = Result<Option<PathInfo>, TransportError>> + Send

How traffic currently reaches the remote (direct, relayed, …), for transports that can tell. Ok(None) means the question does not apply, as for the local transport.

Source

fn forward( &self, request: ForwardRequest, ) -> impl Future<Output = Result<(Forwarder, Receiver<String>), TransportError>> + Send

Forwards a local listener to a port on the remote machine’s localhost, returning the running forwarder and its log lines. Transports without a network (local) refuse.
