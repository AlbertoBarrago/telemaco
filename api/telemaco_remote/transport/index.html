Transports: how bytes reach a remote Telemaco agent.

Every transport yields a Connection, an AsyncRead + AsyncWrite byte stream. The remote protocol is written against that stream only, so it cannot tell Tailcat from a local agent or a future SSH transport. The one place that maps a target to a transport is select_transport.
