Port forwarding over Tailcat: tailcat forward --bind=<ip> <addr> L:R.

Tailcat owns the listener and the tunnel; Telemaco only starts it, reads the # forwarding <local> -> remote <target> line it prints once the listener is up, and tears it down. The server side exposes a port only if remote serve --forward-port named it.
