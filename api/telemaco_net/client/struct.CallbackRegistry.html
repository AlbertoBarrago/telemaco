Struct CallbackRegistry 

Source 
pub struct CallbackRegistry { /* private fields */ }
Expand description

Page-scoped store for the passive on_request/on_response callbacks (issue #408). Each Page owns one, so a callback never fires for another page’s requests and dies with its page. The HTTP client itself stays callback-free; page-driven fetches pass the page’s registry in. Ids keep the u64 shape #416 established on Page::on_request/on_response.
