Module border 

Source
Expand description

Typed CSS border and outline state shared by style, layout, and paint.

CSS keeps the specified border width even while none or hidden makes the used width zero. Keeping those two values distinct is what lets a later border-style: solid restore the previously specified width without corrupting box geometry in the meantime.
