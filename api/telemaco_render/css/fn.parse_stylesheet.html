pub fn parse_stylesheet(css: &str) -> Vec<(String, String)>
Expand description

Split a stylesheet into (selector, declarations) rules. Handles nested braces, /* comments */, and the at-rules that carry ordinary rules inside (@media, @supports, @layer); other at-rules (@font-face, @keyframes, …) are skipped since they do not contribute layout-relevant declarations here.
